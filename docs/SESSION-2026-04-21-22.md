# Session ThumbGen — 21-22 avril 2026

## Ce qui a été fait

### Phase 0 — Installation locale (remplace Cloudflare D1)
- Stockage JSON local dans `data/projects.json`
- Route API `/api/project` (GET/POST) pour load/save
- Docker + docker-compose avec volume `./data:/app/data`

### Phase 2 — Multi-modèles + comparaison

- Checkboxes pour comparer avec d'autres modèles

- Modèle favori sauvé dans settings (étoile jaune)

### Phase 3 — Multi-providers (OpenAI, Grok)
- Routes API `/api/generate/openai` et `/api/generate/grok`

- Route API `/api/projects` (GET/POST/PATCH/DELETE)
- ProjectBar en haut du canvas
- Créer / renommer / supprimer des projets
- Auto-save par projet

- **Prompt IA — mode Écrire** — bouton "Améliorer" context-aware (connaît faces, logos, refs, sketch, prompts précédents)
- **Prompt IA — mode Idées** — suggestions avec checkboxes multi-axes
- **Génération progressive** — Preview nodes en loading, résultats arrivent un par un
- **Stats par image** — temps, tokens, coût estimé, prompt utilisé (avec bouton copier)
- **Couleurs par axe** — bandeau coloré sur chaque Preview

- **Rename** — sur tous les nodes via menu "..."
- **Menu clic droit** — simplifié : Inputs + un seul "Générateur" (modèle favori)

### Prompt engineering
- Structure obligatoire : SUBJECT / COMPOSITION / OBJECTS / TEXT / LIGHTING / STYLE
- Règles anti-contradiction (poses réalistes, cadrages valides, tailles cohérentes)
- Termes interdits ("extreme medium shot", "high-quality", "optimized for CTR")
- Max 2 descripteurs de style
- Face reference gérée par l'image, pas par le texte
- Techniques thumbcraft-skills intégrées

## Architecture technique

### Stack
- Next.js 16 (App Router) + React 19 + TypeScript
- @xyflow/react (canvas node-based)
- Zustand (state management)
- Tailwind CSS v4
- @excalidraw/excalidraw (sketch editor)
- @imgly/background-removal (remove BG client-side)
- Docker + docker-compose

### Structure des fichiers clés
```
src/
├── app/api/
│   ├── enhance-prompt/     # Améliorer un prompt existant
│   ├── suggest-prompts/    # Générer des idées de miniatures
│   ├── generate/
│   │   ├── nano-banana/    # Gemini (tous modèles)
│   │   ├── ideogram/       # Ideogram v3
│   │   ├── openai/         # GPT Image 1/1.5/2
│   │   └── grok/           # Grok Imagine
│   ├── generated-images/   # Stockage/service des images générées
│   ├── face-reactions/     # Upload/service des faces
│   ├── logos/              # Upload/service des logos
│   ├── swipe-files/        # Upload/service des refs
│   ├── projects/           # CRUD projets
│   ├── project/            # Load/save canvas
│   ├── settings/           # Clés API et préférences
│   └── youtube/playlist/   # Import miniatures YouTube
├── components/
│   ├── nodes/              # FaceReference, SwipeFile, Prompt, Generator, Preview, Sketch
│   ├── panels/             # Sidebar, Settings, ProjectBar, ContextMenu, SketchEditor, ZoomBar
│   └── edges/              # CustomEdge
├── lib/
│   ├── settings.ts         # Read/write settings
│   ├── local-storage.ts    # Read/write projects JSON
│   ├── generated-images.ts # Save/serve generated images
│   └── remove-bg.ts        # Background removal
└── store/
    └── canvas-store.ts     # Zustand store (nodes, edges, history, save)
```

### Données persistées
```
data/
├── projects.json           # Tous les canvas (nodes + edges par projet)
├── projects-meta.json      # Métadonnées des projets (nom, dates)
├── settings.json           # Clés API, langue, modèle favori
├── face-reactions/         # Photos de visage uploadées
├── logos/                  # Logos uploadés
├── swipe-files/            # Images de référence
└── generated/              # Images générées (PNG)
```
